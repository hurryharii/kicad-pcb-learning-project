# Motor Driver Circuit PCB — Work in Progress

## Overview
This project is a motor driver circuit PCB designed using KiCad. It is part of my learning journey in electronics and PCB design.

## Components
- 7805 voltage regulator
- 1N4007 diodes
- Capacitors
- Motor connectors
- Test points

## Current Status
The PCB layout is unfinished, with routing and design checks still pending. It has not yet been fabricated or physically tested.
